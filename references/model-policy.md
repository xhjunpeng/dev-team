# 模型与推理策略

使用满足已知风险下限的最低档位。Skill 不自动切换主任务模型；需要升级时先说明原因、收益和额外成本。

此表只用于派单时选择可用模型与思考强度，不覆盖 Agent 配置中的固定模型或权限设置；当前环境不支持时按现有规则报告并选择替代。

| 角色 | 默认 | 按任务覆盖 |
| --- | --- | --- |
| 项目勘察员 | `gpt-5.6-luna` / `medium` | 跨系统追踪用 `gpt-5.6-terra` / `medium` |
| 开发执行员 | `gpt-5.6-terra` / `medium` | 复杂状态或跨模块用 `high` |
| 界面制作员 | `gpt-5.6-terra` / `high` | 单组件可降 `medium`；复杂品牌或 3D 可升 `gpt-5.6-sol` / `high` |
| 独立验收员 | `gpt-5.6-terra` / `high` | 权限、迁移、安全、生产边界用 `gpt-5.6-sol` / `high` 或 `xhigh` |

约束：

- 简单任务不因模型便宜就随意派多个 Agent。
- 不用 `max` 或 `ultra` 作为默认值。
- 同一故障失败后，只有新证据和新假设才能触发模型升级；升级不能代替重新授权。
- 若当前环境不支持表中模型或档位，任务协调员必须报告并选择当前可用的最低合格替代，不静默降级高风险验收。
