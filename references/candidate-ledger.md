# 候选台账

每个明确属于当前任务的候选单独记录。默认只处理当前任务；“盘点”不等于合并或删除授权。

候选分支、worktree、状态和写入范围的可解析记录及与 Git 实况的校验，以 [executable-protocol.md](executable-protocol.md) 为唯一机器规则。本台账只定义人类收口信息。

```text
业务目标：
任务关系：同一未完成业务目标 / 新业务目标 / 归属不明
候选分支：
worktree：
隔离判定：复用当前候选 / 主分支直接写 / 当前目录候选分支 / 独立分支与 worktree / 先收口或明确保留
隔离原因：
唯一写入者：
当前状态：待判断 / 开发中 / 验证中 / 待验收 / 阻塞 / 可收口 / 已收口
未提交与未跟踪内容：
独有提交：
PR / 合并状态：
运行服务绑定：
适用验证：
下一动作：
收口状态：继续开发 / 建议收口 / 阻塞
建议收口动作：提交并推送 / 提交、推送和 PR / 合并并清理当前候选 / 不适用
是否阻止开始新业务目标：是 / 否
是否具备收口条件：
范围冻结版本（v4）：
open 当前阻塞 / 范围变化（v4）：
后续记录（v4）：
事实核验时间：
```

新事实与旧记录冲突时，以重新核验的 Git、文件和远程状态为准，并先报告差异。不要用“分支名像旧任务”推断归属，也不要用干净状态推断已合并。
