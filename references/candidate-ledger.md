# 单份任务记录与交接

每个任务只维护一份 [可执行状态](executable-protocol.md)，主任务是记录唯一写入者。执行员和验收员返回实际证据，由主任务更新。授权、候选、失败、发现、交付和协作事实都写在该记录；人类台账是同一记录的摘要，不另建独立授权卡、失败表或状态副本。

阶段交接只需：固定状态路径与版本、业务目标、准确候选、当前阶段、唯一写入者、关键证据位置、未完成动作与停止条件。收口摘要附当前改动归属、候选/worktree 事实、收口状态（继续开发 / 建议收口 / 阻塞）、是否阻止开始新业务目标及依据。

恢复时读取原状态、授权依据和原始证据，再实时核验 Git、候选所有权、模型可用性、权限和运行态。仅凭摘要、截图、分支名称或“上次通过”不能继续；发现实质差异先报告并停止受影响动作。新会话、换 Agent 和压缩上下文保持同一任务 ID 与失败历史。

本地完成不等于已提交或已启用；协议的“已收口”是任务去向已确定，不可被解释为已合并。实际 Git 动作和检查见 [git-lifecycle.md](git-lifecycle.md)。
