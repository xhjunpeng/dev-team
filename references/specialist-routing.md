# 专业方法

仅在当前工作需要时使用可用专项 Skill；主任务负责范围和交付，不重复执行全局、项目或专项已经覆盖的检查。仅用户调用的 Skill 仍需明确调用。

UI 默认使用 finesse-ui，用户指定设计方法时遵从用户。未知根因且常规检查不足时使用 diagnosing-bugs；用户要求 test-first 时使用 tdd；权限、敏感数据与生产安全使用适用安全方法并保留独立验收。

专业方法决定当前工作的完成标准，不强制把诊断与范围内修复拆成两次派单或授权。Git 操作按 [Git 生命周期](git-lifecycle.md)；故障持续失败按 [诊断与恢复](recovery.md)。
