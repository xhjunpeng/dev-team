# 术语表

- **任务协调员**：保留需求、授权、关键决定、派单、整合和最终验收的主任务。
- **业务目标**：用户期望完成的一项可独立验收的结果；新会话、修复和复核不会自动形成新目标。
- **候选**：承载一个业务目标当前变更的分支及其工作目录。
- **活跃候选**：仍在开发、修复、复核或验收，尚未完成去向确认的候选。
- **唯一写入者**：某个共享文件、模块或可变系统在同一阶段唯一获准修改的角色。
- **项目事实包**：本轮从当前项目重新核验的规则、Git、技术栈、运行态和验证信息。
- **派单包**：任务协调员交给子 Agent 的目标、范围、权限、检查和停止条件。
- **快速路径**：协调成本高于收益时，由主任务直接完成的轻量流程。
- **标准路径**：一个明确写入者完成普通开发并做针对性验证的流程。
- **严格路径**：高风险、难回滚或复杂任务使用隔离、独立验收和回滚边界的流程。
- **故障信号**：能够稳定判断同一用户症状是否存在的测试、命令、请求或浏览器步骤。
- **故障身份、生产修复尝试、诊断工具写入与三次熔断**：以 [recovery.md](recovery.md) 的权威定义为准。
- **收口**：为候选确认成果、验证、合并状态、残留内容和可清理范围；收口不等于清空。
