# 术语

- 任务协调员：保留需求、授权、候选和最终复核的主任务，小修时也可成为唯一写入者。
- 业务目标：用户可以独立验收的一项结果；新会话或返工不自动产生新目标。
- 候选：承载当前目标的分支和准确工作目录。
- 唯一写入者：同一目标同一阶段获准修改共享可变内容的一人或 Agent。
- 难度：理解与实现复杂度；操作风险：对数据、外部系统和恢复能力的实际影响。
- 固定验收：开始时明确的可观察完成标准，不因运行中出现建议而自行提高。
- 故障身份、修复失败、诊断事件和三次停止：以 [recovery.md](recovery.md) 为权威定义。
- 收口：为候选确定成果、验证和去向，分别核验 Git 动作；不等于清空目录或已经上线。
