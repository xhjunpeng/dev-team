# 按实际影响选择流程

普通功能、明确 Bug 和局部 UI 修改默认直接完成，不因调用 dev-team 就建立机器状态。长任务需要简短交接，独立模块并行需要明确责任范围；两者都不自动成为高风险。

权限、重要数据、付款、生产变更、强推和可能丢失成果的操作使用严格协议。合并仍按严格路径核对共享分支影响；已合并且无未保存内容的本地分支或 worktree 清理，可由准确授权与 Git 证据完成，不额外派验收员。

首次写入核对目录、分支、任务归属与已有改动。交接、跨上下文恢复、目录/分支/权限变化、交付以及高风险执行前重查相关事实；同一稳定环境中的连续编辑不重复全量门禁。任务升级只覆盖受影响阶段，不重做已完成工作。
